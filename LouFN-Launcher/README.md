# LouFN Launcher

Native Android launcher app built with Kotlin.

## Current working features
- Detects the official Android Fortnite package `com.epicgames.fortnite`.
- Displays the installed app version.
- Launches Fortnite through Android's package launch intent.
- Builds a debug APK with GitHub Actions.

## Build
Open GitHub Actions → **Build LouFN Launcher APK** → download the **LouFN-Launcher-debug-apk** artifact after a successful run.

This app does not include Fortnite, download game packages, modify game files, bypass anti-cheat, or guarantee compatibility with old Fortnite versions. Install Fortnite only through an official supported source.
