# LouFN OG

Original early-stage 3D battle-arena prototype inspired by retro battle royale games. It is not Fortnite and contains no Epic proprietary code or assets.

GitHub Actions builds a debug Android APK on each push. Open Actions → Build Android APK → download the LouFN-OG-debug-apk artifact after a successful run.

Prototype features: small 3D arena, player capsule, simple moving bots, shooting, touch buttons, and placeable cover. This is not a full Fortnite recreation.
